# Student Management System in C++

This is a simple Student Management System developed using C++. The program allows users to add student records, display all students, search students by ID, and save student information to a text file.

The project is built using Object-Oriented Programming (OOP) concepts such as classes, constructors, encapsulation, and vectors. It also uses file handling to permanently store student data in a text file.

## Features

* Add new student records
* Display all students
* Search students by student ID
* Save student details into a file
* Uses vector for dynamic data storage
* Simple console-based menu system

## Technologies and Concepts Used

* C++
* Classes and Objects
* Constructors
* Vectors (STL)
* File Handling (`ofstream`)
* Loops and Conditional Statements

## File Storage

Student data is stored in:

```text
students.txt
```

## Purpose of the Project

This project was created to practice C++ programming fundamentals and improve understanding of Object-Oriented Programming and file handling concepts.
